# Site de Advocacia — Projeto Pessoal

Este repositório contém o código-fonte de um site desenvolvido como projeto pessoal voltado à área jurídica, com foco em serviços de advocacia. O objetivo principal é o aprendizado e a prática de desenvolvimento web com base em referências reais e profissionais da área.

## ⚖️ Propósito

Este projeto tem como finalidade:

- Estudar e praticar o desenvolvimento de sites institucionais para escritórios de advocacia.
- Reproduzir e adaptar elementos visuais e estruturais de sites existentes, respeitando os direitos autorais e marcas envolvidas.
- Explorar conceitos de design, organização de conteúdo jurídico e boas práticas de apresentação profissional na web.

## 🧩 Fontes de Inspiração

O design, organização de conteúdo e parte da estrutura visual foram inspirados nos seguintes sites:

1. [Marino Advogados](https://marinoadvogados.com.br/advogado-direito-do-consumidor/)
2. [Lamaquia Advogados](https://lamachia.adv.br/areas-de-atuacao/)

Todas as referências foram utilizadas com fins exclusivamente educacionais e demonstrativos, sem qualquer intenção de plágio ou concorrência comercial.

## 🖼️ Imagens

Todas as imagens utilizadas neste projeto foram geradas por meio de inteligência artificial, não sendo retiradas diretamente dos sites de referência ou de bancos de imagem de terceiros.

## 📜 Aviso Legal

Este site é um projeto acadêmico e experimental. Não representa um escritório real de advocacia, tampouco presta serviços jurídicos ao público. Qualquer semelhança com empresas ou marcas é meramente referencial e sem propósito comercial.

As inspirações visuais e estruturais foram utilizadas de acordo com o direito à citação e uso justo para fins de estudo, conforme previsto na legislação de direitos autorais.

Caso algum dos titulares das marcas ou dos sites citados entenda que este projeto infringe direitos autorais, favor entrar em contato para que as devidas providências sejam tomadas.
